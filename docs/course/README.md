# 優待クロス講座（全10回＋付録）

ようこそ！この講座は「株の信用取引をやったことがない人」が、**株主優待クロス取引（つなぎ売り）を安全に、自分ひとりで回せるようになる**ことをゴールにしています。

せどりと同じで、優待クロスも「仕入れ値（コスト）と売値（優待の価値）の差」を積み上げるビジネスです。違うのは、在庫リスク（株価の変動）をほぼゼロにできる点。その代わり、**日付を1日間違えると全部パー**、**コスト計算を間違えると赤字**という世界です。順番に進めてください。

> 本講座の料率・ルールは 2026年9月時点で調べた内容です。証券会社の料率や在庫のルールはよく変わるので、実際に発注する前には必ず各社の公式ページで最新情報を確認してください。本講座は情報提供を目的としたもので、特定の銘柄や証券会社を推奨するものではありません。投資の最終判断はご自身でお願いします。

## おすすめの進め方

1. **1週目**：第1〜3回を読み、証券口座と信用口座を申し込む（信用口座の審査に数日かかります）
2. **2週目**：第4〜6回を読み、ツールの `dates` と `cost` コマンドで練習計算をする
3. **3週目**：少額（株価1,000〜2,000円・100株）の銘柄で1回だけ実際にクロスしてみる
4. **その後**：第7〜10回を読んで、ツールで毎日の「やること」を出しながら数を増やす

最初の1回は「儲けること」より「手順を体で覚えること」が目的です。優待が数百円の銘柄でOK。
