# 第8回　税金と会計（会社員＋せどりの個人事業主向け）

## 今日のゴール

- 優待クロスで出てくるお金が、税金上それぞれ何なのかわかる
- 確定申告で何を書けばいいかわかる
- せどりの帳簿と混ぜない管理方法がわかる

> ここに書いているのは一般的な取扱いです。個別の判断（評価額の決め方、金額が大きい場合など）は税務署か税理士に確認してください。

---

## 1. 全体像：お金ごとに「箱」が違う

| お金 | 税金上の区分 | どこで処理される？ | あなたがやること |
|---|---|---|---|
| **株主優待（品物・金券・優待券）** | **雑所得（その他）**・総合課税 | どこでも自動処理されない | **確定申告書に自分で書く** |
| 貸株料・逆日歩・信用取引の手数料 | 株式等の譲渡所得の費用 | 特定口座で自動計算 | 原則なし |
| 配当（現物側で受取） | 配当所得 | 特定口座（源泉徴収あり）で天引き | 原則なし |
| 配当落調整金（信用売り側で支払） | 譲渡損失として扱われる | 特定口座で自動・配当と損益通算（株式数比例配分方式の場合） | 原則なし |

ポイントは、**株の部分は特定口座が全部やってくれる。優待だけは自分で申告する** ということです。

## 2. 株主優待は「雑所得」

- 株主優待で受けた経済的利益は **雑所得** です（国税庁の確定申告書等作成コーナーにも「株主優待を受け取った場合」の説明があります）
- 金額は **受け取ったときの時価**
  - QUOカード・ギフトカード → 額面
  - 自社製品・食品 → 通常の販売価格など客観的な価格
  - 割引券・食事券など → 評価の考え方が分かれるので、迷ったら税務署・税理士に確認
- 必要経費：クロスのコスト（貸株料など）は **株の譲渡損益側ですでに差し引かれている** ので、優待の雑所得から二重に引かないのが一般的な取扱いです

## 3. 「20万円以下なら申告不要」の誤解

よく聞く「給与以外の所得が20万円以下なら確定申告しなくていい」は、**確定申告をしない会社員向けの特例** です。

あなたは **せどりで確定申告をしている** ので：

- 確定申告をする以上、**優待の雑所得も金額にかかわらず申告に含める**
- せどりの所得と優待の雑所得は、どちらも給与以外の所得として合算されます
- **住民税にはそもそも20万円の特例がない**（確定申告をすれば住民税にも自動で連携されます）

優待は給与・せどりの所得と合算して総合課税されるので、実質の手取りは「優待の価値 ×（1 − あなたの限界税率）」です。ツールの設定 `benefit_tax_rate`（例：所得税20%＋住民税10%なら0.3）を入れると、税引後で判定できます。

## 4. 株の部分：特定口座（源泉徴収あり）なら原則そのまま

- 年明け（1月中）に証券会社から **年間取引報告書** が届く
- 源泉徴収ありの特定口座は **申告不要** を選べる → 何もしなくてOK
- 申告したほうが得になるのは、
  - 複数の証券会社の損益を通算したいとき（例：A社で損、B社で益）
  - 損失を翌年以降に繰り越したいとき（最長3年）
- 株の所得を申告すると、合計所得金額が増えて **住民税や各種控除・扶養の判定に影響する** ことがあります（2024年度分以降、住民税の課税方式も所得税と同じものを選ぶ扱いに統一）。迷ったら申告不要のままが無難です

### 配当の税金はいつ戻る？

一般信用のクロスで配当の権利をまたぐと、現物側の配当から源泉税が引かれ、信用売り側で配当の100%を払います。特定口座（源泉徴収あり）＋株式数比例配分方式なら、口座内で損益通算され、**取られすぎた税金は年間の損益を計算した上で翌年初に還付** されます。

## 5. 優待品・優待券を売った場合（せどり経験者は要注意）

- 優待は **仕入れた商品ではない** ので、**せどりの在庫・売上とは混ぜない**
- 受け取ったときに雑所得として計上するのが原則。受け取ってすぐ金券ショップ等で売った場合、実務上は売却額≒時価として扱われることが多い
- 大量・継続的に売る、評価額と売却額が大きく違う、などの場合は扱いを税理士に確認
- せどりで「他人の優待券を仕入れて売る」のは、優待クロスとは別の **事業の取引** です
- フリマアプリは金券類・プリペイドカードの出品を禁止していることが多いので、各サービスの規約を確認

## 6. 帳簿（会計ソフト）での扱い

優待クロス・株式投資は **せどり事業とは別の、個人の資産運用** です。

| 取引 | 仕訳（事業の帳簿） |
|---|---|
| 事業用口座 → 証券口座に入金 | 借方 **事業主貸** ／ 貸方 普通預金 |
| 証券口座 → 事業用口座に戻す | 借方 普通預金 ／ 貸方 **事業主借** |
| 株の売買・貸株料・配当 | **記帳しない**（特定口座で完結） |
| 優待の受取 | **記帳しない**（確定申告書の雑所得欄に直接入力） |

- できれば **証券口座への入出金は個人用の口座から** 行うと、事業の帳簿に何も出てこないので一番ラクです
- マネーフォワード クラウド確定申告などの申告ソフトでは、雑所得（その他）の入力画面で優待の合計額を入力します

## 7. 記録のつけ方（ツールを使う）

優待が届いたら `mydata/executed.csv` に1行追加します。

```
受取日,コード,銘柄名,優待内容,評価額,売却額,貸株料,逆日歩,手数料,受取配当(税引前),配当落調整金,メモ
2026-06-10,X005,（架空）つばさ航空,株主割引券1枚,1500,2400,352,0,0,5000,5000,金券ショップで売却
```

年が明けたら：

```
$ python -m yutai_cross tax --year 2026 -o mydata/tax_2026.md
```

雑所得（その他）の収入金額の合計、クロス費用の参考値、配当と調整金の合計を1枚にまとめたメモができます。

## 8. 年間の税務スケジュール

| 時期 | やること |
|---|---|
| 優待が届くたび | `executed.csv` に記録 |
| 1月 | 年間取引報告書が届く（特定口座）／配当の源泉税の還付を確認 |
| 1月〜2月 | `tax` コマンドで優待の合計を集計 |
| 2月16日〜3月15日 | 確定申告（せどりの事業所得等＋優待の雑所得） |

## まとめ

- 株の部分は特定口座（源泉徴収あり）＋株式数比例配分方式で **ほぼ自動**
- 優待は **雑所得**。せどりで申告するなら **金額にかかわらず申告に含める**
- 優待品の売却は **せどりと混ぜない**。証券口座との資金移動は **事業主貸／事業主借**
