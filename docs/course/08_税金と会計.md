# 第8回　税金と会計（副業で確定申告している会社員向け）

## 今日のゴール

- 優待クロスで出てくるお金が、税金上それぞれ何なのかわかる
- 確定申告で何を書けばいいかわかる
- 副業（せどりなど）の帳簿と混ぜない管理方法がわかる

> ここに書いているのは、2026年9月時点の税制（2026年分の申告）にもとづく一般的な取扱いです。個別の判断（評価額の決め方、金額が大きい場合など）は税務署か税理士に確認してください。国税庁の[タックスアンサー](https://www.nta.go.jp/taxes/shiraberu/taxanswer/index2.htm)も参照できます。

---

## 1. 全体像：お金ごとに「箱」が違う

| お金 | 税金上の区分 | どこで処理される？ | 自分でやること |
|---|---|---|---|
| **株主優待（品物・金券・優待券）** | **雑所得（その他）**・総合課税 | どこでも自動処理されない | **確定申告書に自分で書く** |
| 貸株料・逆日歩・信用取引の手数料 | 株式等の譲渡損益の計算に含まれる（逆日歩は譲渡収入から控除：所得税基本通達36・37共-22） | 特定口座で自動計算 | 原則なし |
| 配当（現物側で受取） | 配当所得 | 特定口座（源泉徴収あり）で天引き | 原則なし |
| 配当落調整金（信用売り側で支払） | 株式等の譲渡収入から控除（所得税基本通達36・37共-23）→ 結果として譲渡損になり、配当と通算 | 特定口座で自動・配当と損益通算（下の設定をした場合） | 原則なし |

ポイントは、**株の部分は特定口座がほぼやってくれる。優待だけは自分で申告する** ということです。

## 2. 株主優待は「雑所得」

- 株主優待で受けた経済的利益は **雑所得** です（国税庁の確定申告書等作成コーナーにも「株主優待を受け取った場合」の説明があります）
- 金額は **受け取ったときの時価**（所得税法36条2項）
  - QUOカード・ギフトカード・食事券・買物券など額面があるもの → 額面が基本
  - 自社製品・食品・カタログギフト → 通常の販売価格など客観的な価格
  - 割引券（○%引き・運賃割引など）→ 金券ショップの買取価格など換金価値が目安。評価の考え方が分かれるので、金額が大きい場合は税務署・税理士に確認
- 必要経費：クロスのコスト（貸株料など）は **株の譲渡損益側ですでに差し引かれている** ので、優待の雑所得から二重に引かないのが一般的な取扱いです

> 第5回やウォッチリストの「優待価値」は、やるかどうかを判断するための自分なりの見積もりです。確定申告に書く評価額は、受け取った時の時価（客観的な価格）です。自分の感覚で割り引いた額は使えません。

## 3. 「20万円以下なら申告不要」の誤解

よく聞く「給与以外の所得が20万円以下なら確定申告しなくていい」は、年末調整を受けた会社員が確定申告書を出さなくてよい場合の特例（所得税法121条）の話です。20万円は収入ではなく **所得（収入−経費）** で判定します。

せどりなどの副業で **確定申告をしている人** は：

- 確定申告をする以上、**優待の雑所得も金額にかかわらず申告に含める**
- 副業の所得と優待の雑所得は、どちらも給与以外の所得として合算されます
  - せどりが事業所得なら「事業所得」欄、業務に係る雑所得なら「雑所得（業務）」欄に書き、優待は「雑所得（その他）」欄に書きます
  - 雑所得どうしは合算されるので、せどり（業務の雑所得）の赤字は優待と相殺されますが、給与とは損益通算できません
- **住民税にはそもそも20万円の特例がない**（確定申告をすれば住民税にも自動で連携されます）

優待は給与・副業の所得と合算して総合課税されるので、実質の手取りは「優待の時価 ×（1 − 自分の限界税率）」です。ツールの設定 `benefit_tax_rate`（例：所得税20%〔復興特別所得税込みで20.42%〕＋住民税10%なら 0.3042）を入れると、税引後で判定できます。

## 4. 株の部分：特定口座（源泉徴収あり）なら原則そのまま

- 翌年1月（1月31日まで）に証券会社から **年間取引報告書** が届く
- 源泉徴収ありの特定口座は **申告不要** を選べる → 何もしなくてOK
- 申告したほうが得になるのは、
  - 複数の証券会社の損益を通算したいとき（例：A社で損、B社で益）
  - 損失を翌年以降に繰り越したいとき（最長3年）
- 株の所得を申告すると、合計所得金額が増えて **住民税や各種控除・扶養の判定に影響する** ことがあります。2023年分の所得に対する住民税（2024年度分）から、所得税で申告した株の所得は住民税でも申告したものとして扱われ、住民税だけ申告不要にすることはできなくなりました。迷ったら申告不要のままが無難です

### 配当の税金はいつ戻る？

一般信用のクロスで配当の権利をまたぐと、現物側の配当から源泉税が引かれ、信用売り側で配当の100%を払います。特定口座（源泉徴収あり）＋株式数比例配分方式＋特定口座で配当を受け入れる設定をしていれば、**同じ年・同じ特定口座の中で** 損益通算され、**取られすぎた税金は年間の損益を計算したうえで翌年1月上旬に還付** されます。

## 5. 優待品・優待券を売った場合（せどりをしている人は要注意）

- 優待は **仕入れた商品ではない** ので、**せどりの在庫・売上とは混ぜない**
- 受け取ったときの時価で雑所得に計上するのが原則です。受け取ってすぐ金券ショップ等で売った場合は、その売却額（買取価格）を時価として評価額に書くのが実務的です
- 時間をおいて売って評価額との差が出た場合、差額は別の所得として扱う考え方があるので、金額が大きいときは税理士に確認してください
- 優待品は個人（家事用）の資産なので、売っても通常はせどり事業の売上ではなく、**消費税の課税売上にも入れません**（消費税法基本通達5-1-1（注））。インボイス登録していても同じです。ただし、せどりのアカウントや在庫と一緒に継続的に売ると事業の取引と見られる余地があるので、**出品アカウントと入金先は分けてください**
- せどりで「他人の優待券を仕入れて売る」のは、優待クロスとは別の **事業の取引** です
- フリマアプリは金券類・プリペイドカードの出品を禁止していることが多いので、各サービスの規約を確認

## 6. 帳簿（会計ソフト）での扱い

優待クロス・株式投資は **副業の事業とは別の、個人の資産運用** です。

| 取引 | 仕訳（事業の帳簿） |
|---|---|
| 事業用口座 → 証券口座に入金 | 借方 **事業主貸** ／ 貸方 普通預金 |
| 証券口座 → 事業用口座に戻す | 借方 普通預金 ／ 貸方 **事業主借** |
| 株の売買・貸株料・配当 | **記帳しない**（特定口座で完結） |
| 優待の受取 | **記帳しない**（確定申告書の雑所得欄に直接入力） |
| 優待品をせどり用アカウントで売り、代金が事業用口座に入金された | 借方 普通預金 ／ 貸方 **事業主借**（売上にしない。その販売手数料・送料も事業の経費にしない） |
| 優待のQUOカード等で事業用の消耗品を買った | 借方 消耗品費 ／ 貸方 **事業主借** |

- できれば **証券口座への入出金は個人用の口座から** 行うと、事業の帳簿に何も出てこないので一番ラクです
- マネーフォワード クラウド確定申告などの申告ソフトでは、雑所得（その他）の入力画面で優待の合計額を入力します

## 7. 記録のつけ方（ツールを使う）

優待が届いたら、建玉を記録していれば次のコマンドで `mydata/executed.csv` に1行追加されます（貸株料・配当は見込み値なので、取引報告書の値で直してください）。

```
$ python -m yutai_cross position received 1 --value 3000          # 売ったなら --sold 2400 も
```

建玉を記録していない場合は、Excel で `mydata/executed.csv` に直接1行追加します（`init` で見出しだけのファイルができています）。

```
受取日,コード,銘柄名,優待内容,評価額,売却額,貸株料,逆日歩,手数料,受取配当(税引前),配当落調整金,メモ
2026-06-10,X005,（架空）つばさ航空,株主割引券1枚,2400,2400,352,0,0,5000,5000,受取直後に金券ショップで売却（売却額を時価とした）
```

- 評価額：受け取った時の時価（上の §2）。すぐ売ったなら売却額と同じにする
- Excel で保存すると日付が `2026/6/10` の形になりますが、そのままで読めます

年が明けたら：

```
$ python -m yutai_cross tax --year 2026 -o mydata/tax_2026.md
```

雑所得（その他）の収入金額の合計、クロス費用の参考値、配当と調整金の合計を1枚にまとめたメモができます。評価額と売却額が違う行や、評価額が0円の行は「見直してほしい行」として表示されます。

## 8. 年間の税務スケジュール

| 時期 | やること |
|---|---|
| 優待が届くたび | `position received` で記録（または `executed.csv` に直接追加） |
| 1月 | 年間取引報告書が届く（特定口座）／配当の源泉税の還付を確認 |
| 1月〜2月 | `tax` コマンドで優待の合計を集計 |
| 2月16日〜3月15日 | 確定申告（副業の所得＋優待の雑所得） |

## まとめ

- 株の部分は特定口座（源泉徴収あり）＋株式数比例配分方式＋配当の受入設定で **ほぼ自動**
- 優待は **雑所得**。評価額は受け取った時の時価。確定申告するなら **金額にかかわらず申告に含める**
- 優待品の売却は **副業の売上と混ぜない**。証券口座との資金移動は **事業主貸／事業主借**
