# 付録　優待クロス チェックリスト

## 銘柄を決めるとき

- [ ] 会社のIRで優待内容・権利確定日・必要株数を確認した
- [ ] 長期保有条件がない（または継続クロスのつもりで条件を理解している）
- [ ] 優待の廃止・変更のお知らせが出ていない
- [ ] 勤務先・取引先・グループ会社の銘柄ではない（未公表の重要事実を知っていない）
- [ ] `plan` で見込み利益が最低ライン以上、損益分岐日も確認した

## 発注の前夜〜当日 8:59

- [ ] `today` / `dates` で **権利付最終日** を確認した（今日が権利付最終日より後ではない）
- [ ] 一般信用の **売り在庫** が必要株数以上ある
- [ ] 保証金・買付余力が足りている
- [ ] **① 信用売り**：新規売／一般信用（短期 or 無期限）／必要株数／成行／**寄付**
- [ ] **② 現物買い**：現物買／同じ株数／成行／**寄付**／預り区分 **特定**
- [ ] ①→②の順に、続けて発注した

## 9:00 以降（約定確認）

- [ ] 両方とも約定した
- [ ] 株数が同じ
- [ ] 約定単価が同じ
- [ ] 片方だけなら第4回 STEP5 の対処をした
- [ ] `position add` で建玉を記録した（またはウォッチリストの「クロス済」に○）

## 権利付最終日まで

- [ ] 何もしない（現渡しも売りもしない）
- [ ] 会社の適時開示（優待変更・分割・TOBなど）をたまに確認

## 権利落ち日

- [ ] **現渡し（品渡し）** を発注した（返済買いではない。短期初日に建てた場合はこの日が返済期日）
- [ ] 現渡しが約定し、建玉と現物が両方消えた
- [ ] 返済期日までに終わった
- [ ] `position close` で記録した（「クロス済」の○を使った場合は空欄に戻した）

## 優待が届いたら

- [ ] `position received` で記録した（評価額＝受け取った時の時価。売ったなら --sold で売却額）
- [ ] 使う／換金するを決めた（換金するなら、せどりの帳簿とは別に管理）

## 年明け

- [ ] 年間取引報告書を受け取った
- [ ] `python -m yutai_cross tax --year <年>` で優待の雑所得を集計した
- [ ] 確定申告書の「雑所得（その他）」に記入した
