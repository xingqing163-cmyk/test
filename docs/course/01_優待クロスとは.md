# 第1回　優待クロスとは

## 今日のゴール

- 株主優待がもらえる条件を説明できる
- 「現物買い＋信用売り」で株価の上げ下げが打ち消し合う理由がわかる
- 優待クロスで「残るもの」と「かかるもの」がわかる

---

## 1. 株主優待のおさらい

多くの上場企業は、**決まった日（権利確定日＝基準日）に株主名簿に載っている人**に、自社製品・食事券・QUOカードなどの「株主優待」を送っています。条件はだいたい「100株以上」。

普通にもらおうとすると、株を買って持っておく必要があります。でも株価は動きます。

- 2,000円 × 100株 ＝ 20万円で買った株が、権利を取ったあとに1,800円に下がったら **−2万円**
- 優待はQUOカード1,000円 → **差し引き −1万9千円**

実際、権利落ち日（権利付最終日の翌営業日）は、優待や配当を取り終えた人が売るので株価が下がりやすい傾向があります。**優待のために株価リスクを背負うのは割に合わないことが多い**のです。

## 2. クロス取引のアイデア

そこで、同じ銘柄を **同じ株数・同じ値段で**

- **現物で買う**（株価が上がると得、下がると損）
- **信用取引で売る（空売り）**（株価が下がると得、上がると損）

を同時に行います。これが **クロス取引（つなぎ売り）** です。

```
                 株価 2,000円 → 1,800円 に下がった場合
  現物買い 100株    ：  −20,000円
  信用売り 100株    ：  +20,000円
  ─────────────────────────────
  合計              ：        0円   ← 株価がいくらになっても相殺
```

上がっても同じです（現物 +、信用売り −）。つまり **株価変動の損益がゼロに固定** されます。

それでいて、**現物100株は自分のもの**なので、権利確定日の株主名簿にはあなたの名前が載ります。→ **優待がもらえる**。

## 3. 最後は「現渡し」で終わらせる

権利が確定したら（正確には権利落ち日になったら）、手持ちの現物株を、信用売りの返済に「そのまま差し出して」終わりにします。これを **現渡し（げんわたし／品渡し）** といいます。

```
  現物100株 ──（差し出す）──▶ 信用売り100株の返済
  株の出入りなし・売買の値ズレなし・手数料もかからないことが多い
```

せどりで例えるなら「仕入れた商品を、先に受けていた注文にそのまま納品する」イメージです。

## 4. 残るもの・かかるもの

| 残るもの | かかるもの（コスト） |
|---|---|
| 株主優待 | 貸株料（信用売りで株を借りるレンタル料） |
| | 逆日歩（制度信用のとき、株が足りないと発生する追加料金） |
| | 売買手数料（0円の証券会社が多い） |
| | 配当まわりの税金のズレ（設定次第でほぼゼロにできる） |

つまり **利益 ＝ 優待の価値 − コスト**。「タダ取り」と呼ばれることもありますが、正確には **「安く仕入れる」** 手法です。このコストをきちんと計算し、見合う銘柄だけやるのが勝ち筋です（第5回で詳しく）。

株価の損得は打ち消せても、**リスクがゼロになるわけではありません**。逆日歩（制度信用）、追証、片方だけ約定する、強制決済される、といった場面では損失が出ることがあります（第6回）。

## 5. 法律上の注意（仮装売買）

優待クロスは、証券会社自身が「優待クロス取引」「つなぎ売り」として案内している一般的な手法です。ただし、同じ人が同じ銘柄を同時に売り買いするので、出し方には注意が必要です。

- 金融商品取引法159条は、売買が盛んだと他人に誤解させる等の目的で、権利の移転を目的としない仮装の売買をすることを禁止しています（刑事罰・課徴金の対象）
- 現物買いと信用売りは、**寄付前に「寄成（よりなり）」×「寄成」**（間に合わなければ「引成」×「引成」）で、**同じ株数を続けて**発注する
- **取引時間中に成行や同じ値段の指値で売り買いしない**。株価を動かすような出し方をしない
- **普段の出来高に比べて大きすぎる株数ではやらない**
- 別々の証券会社で現物と信用売りを組むと、証券会社の注文制御が効かないので、上のルールを自分で守る
- 証券会社から注意や問い合わせを受けたら、取引を止めて指示に従う

証券会社の側でも対策をしています。例えばSBI証券は、クロスになる注文のうち「成行×成行」を受け付けず、「寄成」「引成」などの執行条件を付ける必要があります。楽天証券も、取引時間中に約定するクロス注文は受け付けず、「寄付」か「引け」の指定を求めています（2026年9月時点）。

## まとめ

- 現物買い＋信用売りを同時に行うと、株価変動の損益は相殺される
- 権利確定日に株主名簿に載るので優待がもらえる
- 権利落ち日に現渡しで終わらせる
- 利益 ＝ 優待の価値 − コスト（貸株料・逆日歩・手数料など）
