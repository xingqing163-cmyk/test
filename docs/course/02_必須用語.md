## A. 日付の用語（いちばん大事）

| 用語 | 意味 | 覚え方 |
|---|---|---|
| **権利確定日（基準日）** | この日の株主名簿に載っている人が優待をもらえる。多くは月末、20日などもある | 会社が決める「締め日」 |
| **受渡日** | 売買した株と代金が実際にやり取りされる日。**約定日の2営業日後（T+2）** | 買った株が「自分のもの」になる日 |
| **権利付最終日** | この日までに買えば（受渡日が確定日に間に合うので）権利がもらえる最後の日。**権利確定日の2営業日前** | ここでクロスが完了していればOK |
| **権利落ち日** | 権利付最終日の翌営業日。この日以降に売っても権利は残る | **現渡しはこの日以降** |

ポイント：

- **権利確定日が土日・祝日・年末の休場日**のときは、その前の営業日が実質の確定日になり、そこから2営業日さかのぼります。例：2026年10月31日（土）→ 実質10月30日（金）→ 権利付最終日は **10月28日（水）**
- 12月31日は東証が休場なので、12月末権利の権利付最終日は例年早めになります（2026年は **12月28日（月）**）
- 間違えやすいので、日付は必ずツールの `dates` コマンドで確認する習慣を

## B. 取引の用語

| 用語 | 意味 |
|---|---|
| **現物取引** | 自分のお金で株を買う普通の取引 |
| **信用取引** | 証券会社にお金や株を借りて取引すること。専用の「信用取引口座」が必要 |
| **空売り（信用売り・新規売り）** | 株を借りて売ること。後で買い戻す（または現渡しする）ことで返す |
| **建玉（たてぎょく）** | まだ返済していない信用取引のポジション |
| **現渡し（品渡し）** | 手持ちの現物株で、信用売りの建玉を返済すること。クロスの最後はこれ |
| **返済買い** | 市場で株を買い戻して信用売りを返すこと。**クロスでは使わない**（現渡しを使う） |
| **寄成（よりなり）** | 「寄付（9:00の最初の取引）で成行で約定させる」注文条件。クロスの基本 |
| **引成（ひけなり）** | 「大引け（15:30の最後の取引）で成行で約定させる」注文条件。寄付に間に合わなかったときの手段 |

※東証の取引時間は 2024年11月から 9:00〜11:30／12:30〜15:30 です。

## C. 信用取引の種類

| 種類 | 特徴 | クロスでの使い方 |
|---|---|---|
| **制度信用** | 取引所のルールで決まった信用取引。返済期限6ヶ月。売れるのは「貸借銘柄」だけ | **逆日歩リスクあり**。上級者向け |
| **一般信用** | 証券会社が独自に用意する信用取引。証券会社が株を調達して貸してくれる | **逆日歩がない**ので初心者はこちら。ただし「在庫」がないと売れない |
| └ 短期 | 返済期限が短い（例：SBI証券15営業日、楽天証券14日）。優待銘柄を中心に在庫が用意される | 優待クロスの主力 |
| └ 無期限（長期） | 返済期限なし。貸株料が安い | 在庫があればコスト最安 |
| └ 日計り（いちにち信用） | その日のうちに返済が必要 | 権利をまたげないので**クロスには使えない** |

## D. コストの用語

| 用語 | 意味 |
|---|---|
| **貸株料** | 空売りで株を借りるレンタル料。約定代金×年率×日数÷365。一般信用の短期は年3.9%程度、無期限は年1.1%程度（2026年9月時点・SBI証券／楽天証券の例） |
| **逆日歩（ぎゃくひぶ）／品貸料** | 制度信用で、売りが多すぎて株が足りなくなったときに売り方が払う追加料金。**事前に金額がわからない**。人気優待銘柄の権利付最終日は高くなりやすい |
| **最高料率** | 逆日歩の上限。日本証券金融（日証金）が株価帯ごとに決めている。**権利付最終日は上限が4倍**、異常時は10倍になることも |
| **配当落調整金** | 信用売りで配当の権利日をまたいだとき、売り方が払うお金。一般信用は配当の100%、制度信用は84.685% |
| **委託保証金** | 信用取引の担保。建玉の30%以上、かつ最低30万円が必要 |
| **代用有価証券** | 保証金の代わりに差し入れられる株（評価は時価の80%程度） |

## E. 株主名簿の用語

| 用語 | 意味 |
|---|---|
| **株主番号** | 株主名簿で株主を識別する番号。長期保有の判定に使われることが多い |
| **長期保有条件** | 「1年以上継続保有」など、続けて株主でないと優待が出ない（または増えない）条件。**1回のクロスでは満たせない** |

## F. 在庫の用語

| 用語 | 意味 |
|---|---|
| **在庫（売建可能数量）** | 一般信用で売れる残りの株数。先着順。なくなると注文できない |
| **短期初日** | 一般信用（短期）で、返済期限内に権利落ち日の現渡しが収まる最初の日。権利落ち日から返済期限の営業日数だけさかのぼった日。人気銘柄の在庫はこの日（の前夜）に一気になくなる |

## まとめ

- 日付：**権利付最終日までにクロス、権利落ち日以降に現渡し**
- 種類：初心者は **一般信用（短期）** を使う（逆日歩がない）
- コスト：**貸株料**は計算できる、**逆日歩**は事前にわからない
