# 第5回　コスト計算をマスターする

## 今日のゴール

- 貸株料を自分で計算できる
- 逆日歩の上限の目安を見積もれる
- 配当まわりの税金のズレを理解する
- 「やる・やらない」を数字で判断できる

---

## 基本式

```
利益 ＝ 優待の価値 −（貸株料 ＋ 逆日歩 ＋ 手数料 ＋ 配当まわりのズレ）
```

せどりの「粗利 ＝ 売価 − 仕入 − 手数料 − 送料」と同じ考え方です。

## 1. 貸株料（一般信用・制度信用の両方）

```
貸株料 ＝ 約定代金 × 年率 × 日数 ÷ 365   （円未満切り捨て）
日数   ＝ 新規売りの受渡日 〜 現渡しの受渡日（両端を含む）
```

- 日数は **受渡日ベースの暦日**。土日祝をまたぐと増えます
- 権利付最終日にクロスして翌営業日に現渡ししても、**最低2日分** かかります
- 両端入れか片端入れかは証券会社のルールで決まるので、ツールの設定 `day_count` で切り替えられます（初期値は両端入れ）

### 例：株価2,000円×100株＝約定代金20万円

| ケース | 年率 | 日数 | 貸株料 |
|---|---|---|---|
| 最終日クロス（受渡日が平日で連続） | 3.9% | 2日 | 42円 |
| 最終日クロス（受渡日が金曜→月曜） | 3.9% | 4日 | 85円 |
| 12月末の最終日クロス（年末年始をまたぐ） | 3.9% | 6日 | 128円 |
| 15営業日前に早めにクロス | 3.9% | 22日 | 470円 |
| 無期限で15営業日前にクロス | 1.1% | 22日 | 132円 |

**早くクロスするほど、日数ぶんだけコストが増える** のがポイント。「在庫を確保する安心料」とのトレードオフです（第7回）。

## 2. 逆日歩（制度信用だけ）

```
逆日歩 ＝ 1株あたりの品貸料（円/日） × 株数 × 日数
日数   ＝ 新規売りの受渡日から、現渡しの受渡日の前日まで（暦日・片端入れ）
```

逆日歩は **売り終わった後に決まる** ので、事前に正確な金額はわかりません。目安になるのは **最高料率** です（ただし臨時措置で引き上げられることがあり、絶対の上限ではありません）。

- 最高料率は日本証券金融（日証金）が株価帯ごとに決めていて、**株価のおよそ0.2%／日**（1株あたり）
- **権利付最終日は上限が4倍**（権利落ち日の6営業日前〜2営業日前は2倍）
- 極端な株不足では、臨時措置で10倍になることもある

出典：日本証券金融「[品貸入札、逆日歩、最高料率](https://www.taisyaku.jp/about/backwardation/)」「[最高料率早見表](https://www.taisyaku.jp/media/about-hayamihyo.pdf)」（2026年9月確認）

### 例：株価2,000円（最高料率 約4円）×100株、権利付最終日に制度信用で売り

| ケース | 1株1日（最高料率×4倍） | 日数 | 逆日歩の見積もり |
|---|---|---|---|
| 受渡日が平日で連続 | 4円×4倍＝16円 | 1日 | 1,600円 |
| 受渡日が金曜→月曜（例：2026年10月末） | 16円 | 3日 | **4,800円** |
| 年末年始をまたぐ（2026年12月末） | 16円 | 5日 | **8,000円** |

優待がQUOカード1,000円なら、最高料率×4倍で計算すると **7,000円の赤字** です（臨時措置で10倍になれば、さらに増えます）。これが「制度信用クロスは上級者向け」と言われる理由です。ツールは初期設定で **制度信用を最高料率×4倍の逆日歩で判定** するので、ほとんどの場合「見送り」になります。

> ツールの最高料率は「株価帯の上限×0.2%」で近似しています。正確な値は日証金の「最高料率早見表」で確認し、ウォッチリストの「逆日歩最悪」列（円/株/日）に入れると上書きできます。

## 3. 手数料

主要ネット証券は国内株の売買手数料が0円のプランがあります（条件あり）。現渡しは多くの証券会社で手数料がかかりません。有料の証券会社を使う場合は設定 `commission_buy` / `commission_short` に入れます。

## 4. 配当まわりのズレ

権利確定日をまたぐと、配当が関係してきます。

- 現物：配当を受け取る（源泉徴収 20.315% を引かれる。所得税15.315%〔復興特別所得税を含み2037年分まで〕＋住民税5%）
- 信用売り：配当落調整金を払う（**一般信用は配当の100%**、**制度信用は84.685%**）

### 例：1株30円×100株＝配当3,000円

| | 株式数比例配分＋特定口座で自動通算される | 自動で通算されない場合（配当金領収証方式など。確定申告すれば通算は可能） |
|---|---|---|
| 一般信用 | **±0円**（取られすぎた税金が年明けに戻る） | **−609円** |
| 制度信用 | **＋366円**（少し得） | −150円 |

→ 第3回でやった **「特定口座（源泉徴収あり）＋株式数比例配分方式」** の設定が効いてきます。設定していないと、高配当銘柄ほど損が大きくなります。

※損益通算による還付は、同じ年・同じ特定口座の損益全体で計算されるので、戻るのは基本的に翌年1月上旬です。

## 5. 優待の価値をどう見積もるか

| 優待の種類 | 見積もり方の例 |
|---|---|
| QUOカード・ギフトカード | 額面 |
| 自社製品・食品 | 「自分が普段その値段で買うか？」で割り引いて考える |
| 食事券・割引券 | 実際に使う見込みがあるか。使わないなら換金価値で |
| 株主優待券（航空・鉄道など） | 金券ショップ・フリマの相場（換金価値） |

ツールでは

- **優待価値**：自分で使う場合の価値
- **換金価値**：金券ショップ等で売った場合の価値

を別々に入力でき、設定 `valuation` でどちらで判定するか選べます。せどりの経験がある人なら、換金価値の見積もりは得意分野のはずです。

> ここでの「優待価値」は、やるかどうかを判断するための自分なりの見積もりです。確定申告に書く金額は、受け取った時の時価（金券なら額面など、客観的な価格）です。自分の感覚で割り引いた額は使えません（第8回）。

## 6. 資金効率（利回り）

```
1回の利回り ＝ 利益 ÷ 必要資金（現物代金＋保証金）
```

同じ利益1,000円でも、必要資金が10万円の銘柄（1%）と100万円の銘柄（0.1%）では効率が10倍違います。資金が限られているうちは **利回りの高い銘柄を優先** しましょう。ツールのランキングにも利回りが出ます。

## まとめ

- 貸株料は計算できる：約定代金×年率×日数÷365（受渡日ベース・連休で増える）
- 逆日歩は上限の目安で考える：株価の約0.2%×4倍×日数（臨時措置でさらに増えることもある）
- 配当のズレは「株式数比例配分方式」でほぼゼロ
- 優待の価値は「使うか・売るか」で見積もる
