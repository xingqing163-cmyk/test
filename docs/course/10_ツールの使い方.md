# 第10回　自動検出ツールの使い方

## 今日のゴール

- ツールをセットアップして、自分のウォッチリストで動かせる
- 「どれを・いつ・どの方法で建てて・いつ現渡しするか」をツールに出させる
- 毎日自動で実行する仕組みを作れる

---

## 1. ツールがやってくれること

| 機能 | コマンド |
|---|---|
| 候補ランキング（見込み利益・利回り・推奨方法・推奨エントリー日・損益分岐日） | `plan` |
| 今日と次の営業日にやること（エントリー・最終日・短期初日・現渡し） | `today` |
| 権利付最終日・権利落ち日・短期初日の計算 | `dates` |
| 1銘柄のコスト試算 | `cost` |
| 確定申告用メモ | `tax` |
| スマホのカレンダーに入れられるファイル（.ics） | `plan -o` |

**ツールがやらないこと**：一般信用の在庫の確認、発注、優待情報の収集。これらは証券会社の画面と会社のIRで行います（ログインが必要・利用規約の制約があるため）。

## 2. セットアップ

必要なもの：Python 3.9 以上（追加のライブラリは不要）

```bash
git clone <このリポジトリ>
cd <リポジトリのフォルダ>
python -m yutai_cross init        # mydata/ にサンプルをコピー
python -m yutai_cross plan        # サンプル（架空銘柄）で動作確認
```

`mydata/` はあなた専用のフォルダです（git の管理対象外にしてあります）。

## 3. ウォッチリストを作る（`mydata/watchlist.csv`）

Excel で開いて編集できます（UTF-8 でも Shift_JIS でも読めます）。1行＝1銘柄。

| 列 | 必須 | 書き方の例 | 説明 |
|---|---|---|---|
| コード | ○ | `7203`、`130A` | 銘柄コード |
| 銘柄名 | | `○○食品` | |
| 権利月 | ○ | `3`、`3・9` | 複数の月は「・」「;」「/」で区切る |
| 権利日 | | `末`、`20` | 空欄は月末 |
| 必要株数 | | `100` | 空欄は100 |
| 株価 | △ | `1850` | 貸株料の計算に使う。`--fetch-prices` か `--prices` で上書き可 |
| 優待内容 | | `QUOカード1000円` | メモ用 |
| 優待価値 | ○ | `1000` | 自分で使う場合の価値（円） |
| 換金価値 | | `950` | 売った場合の価値（円）。設定 `valuation` を `resale` にするとこちらで判定 |
| 1株配当 | | `20` | その権利日の1株配当（予想） |
| 貸借 | | `○` / `×` | 貸借銘柄なら○（制度信用で売れる） |
| 一般信用 | | `SBI短期;楽天短期` | 一般信用で売れる方法。空欄＝全社の全方法を候補、`なし`＝一般信用不可 |
| 長期条件 | | `1年以上継続保有` | 書くと初期設定では見送り |
| 人気 | | `高` / `中` / `低` | 先回りの度合い（第7回）。空欄は中 |
| 逆日歩想定 | | `2` | 制度信用の逆日歩の見込み（円/株/日） |
| 逆日歩最悪 | | `16` | 最悪ケース（円/株/日）。空欄なら株価から自動で概算（最高料率×4倍） |
| メモ | | | 自由記入 |
| 有効 | | `○` / `×` | ×にすると一時的に無視 |

「一般信用」列には、証券会社名（`SBI`、`楽天`）、証券会社名＋期限（`SBI短期`、`楽天無期限`）、設定の id（`sbi_short`）が使えます。

`#` で始まる行はコメントです。

## 4. 設定（`mydata/settings.json`）

主な項目（全項目の説明はファイル内のコメント参照）：

| 項目 | 初期値 | 意味 |
|---|---|---|
| `valuation` | `benefit` | `benefit`＝優待価値で判定、`resale`＝換金価値で判定 |
| `min_profit_yen` | 300 | これ未満の利益なら見送り |
| `horizon_days` | 60 | 何日先の権利付最終日まで見るか |
| `popularity_premium` | 高0.5／中0.3／低0 | 先回りの貸株料に、最安時の利益の何割まで使うか |
| `max_lookback_business_days` | 10 | 無期限の一般信用で何営業日前まで先回りを検討するか |
| `dividend_tax_recovered` | true | 株式数比例配分方式で配当の税が戻るなら true |
| `benefit_tax_rate` | 0 | 優待にかかる税率の目安（例 0.3） |
| `seido_risk_basis` | `worst` | 制度信用を最悪ケースで判定するか |
| `exclude_codes` | [] | **勤務先・取引先など売買しない銘柄コード** |
| `include_long_term` | false | 長期保有条件つき銘柄も推奨に含めるか |
| `methods` | SBI・楽天・制度 | 証券会社ごとの料率・返済期限・手数料。**最新の料率に更新して使う** |

証券会社を追加したい場合は `methods` に1つ追加します：

```json
{"id": "xxx_short", "broker": "XXX", "label": "XXX証券 一般信用(短期)", "kind": "ippan",
 "lending_rate": 0.039, "max_hold_business_days": 15, "day_count": "both",
 "commission_buy": 0, "commission_short": 0, "enabled": true}
```

## 5. 毎日の使い方

### 候補ランキングとスケジュール

```bash
python -m yutai_cross plan -o mydata/reports
```

出力の見方：

- **今日／次の営業日にやること**：`[エントリー]` `[最終日]` `[短期解禁]` `[現渡し]`
- **おすすめ候補**：見込み利益の大きい順。推奨方法・推奨エントリー日・建て可能開始日・損益分岐日・利回り・状態
- **見送り**：利益不足、長期条件、売建不可など
- **注意事項**：在庫確認、逆日歩、長期条件など
- **必要資金ピーク**：推奨どおりに建てたときに同時に必要なお金の目安

`mydata/reports/` には次のファイルができます：

- `plan_YYYYMMDD.md`：銘柄ごとの詳しい手順とコスト内訳、方法別の比較表
- `plan_YYYYMMDD.csv`：Excel で開ける一覧
- `yutai_cross.ics`：推奨エントリー日・短期初日・権利付最終日・現渡し日のカレンダー。Googleカレンダーなどに読み込めます

### 今日やることだけ見る

```bash
python -m yutai_cross today
```

### 株価を自動で取る（任意）

```bash
python -m yutai_cross plan --fetch-prices
```

Yahoo!ファイナンスの非公式データを使うため、取れないこともあります。その場合はウォッチリストの株価を使います。証券会社からダウンロードした「コード,株価」の CSV を `--prices ファイル名` で渡すこともできます。

## 6. 毎日自動で実行する

### Mac / Linux（cron）

毎日20時に「今日と明日やること」をファイルに書き出す例：

```
0 20 * * 1-5 cd /path/to/repo && /usr/bin/python3 -m yutai_cross today > mydata/today.txt 2>&1
```

### Windows（タスクスケジューラ）

1. タスクスケジューラ → 基本タスクの作成 → 毎日 20:00
2. 操作：プログラムの開始
   - プログラム：`python`
   - 引数：`-m yutai_cross today`
   - 開始：リポジトリのフォルダ

`today --exit-code` にすると、やることがない日は終了コード1になるので、「やることがある日だけ通知する」仕組みも作れます。

### カレンダーに入れる

`plan -o mydata/reports` でできた `yutai_cross.ics` を Googleカレンダーの「インポート」で読み込むと、スマホに予定が出ます（週1回くらい更新して読み込み直す）。

## 7. ツールの判定ロジック（しくみ）

1. **日程計算**：権利確定日 → 実質の確定日（休場なら前営業日）→ 2営業日前が権利付最終日 → 翌営業日が権利落ち日。祝日は祝日法のルールで計算、年末年始（12/31〜1/3）も休場
2. **方法ごとのコスト**：売建方法（証券会社×短期/無期限、制度信用）ごとに、各営業日にクロスした場合の貸株料・逆日歩（想定／最悪）・手数料・配当まわりのズレを計算
3. **建て可能期間**：一般信用（短期）は権利落ち日から返済期限の営業日数だけさかのぼった日から。無期限は `max_lookback_business_days` まで。制度信用は権利付最終日のみ
4. **損益分岐日**：最低利益を確保できる最も早い日
5. **推奨エントリー日**：人気に応じた割合（`popularity_premium`）まで貸株料が増えてもよい範囲で、最も早い日
6. **推奨方法**：推奨日の利益が最も大きい方法（制度信用は初期設定では最悪ケースの利益で比較）
7. **ランキング**：見込み利益の大きい順

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| 「ウォッチリストが見つかりません」 | `python -m yutai_cross init` を実行 |
| 「株価が未設定のためスキップ」 | ウォッチリストに株価を入れるか `--fetch-prices` |
| 「〇行目: 権利月が不正です」 | 権利月は1〜12の数字で |
| 全部「見送り」になる | `min_profit_yen` が高すぎないか、優待価値が正しいか確認 |
| 日付が証券会社の表示と違う | 臨時休場などがあれば設定 `extra_market_holidays` に追加。それでも違えば証券会社の表示を優先 |

## 宿題（卒業課題）

1. 自分のウォッチリストを10銘柄作る
2. `plan -o mydata/reports` を実行し、1位の銘柄の Markdown レポートを読む
3. 次の権利月で、在庫を確認して1銘柄クロスしてみる（付録のチェックリストを使って）
4. 優待が届いたら `executed.csv` に記録する

おつかれさまでした！ここまでできれば、優待クロスを自分で回せます。
