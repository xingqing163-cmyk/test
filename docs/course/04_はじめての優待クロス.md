# 第4回　はじめての優待クロス（実践）

## 今日のゴール

架空の銘柄で、**銘柄選び → 日程確認 → 在庫確認 → 発注 → 約定確認 → 現渡し → 優待受取** までを一通り体験する。

---

## 題材

| 項目 | 内容 |
|---|---|
| 銘柄 | （架空）みなとドラッグ |
| 権利確定日 | 12月末（2026年12月31日） |
| 必要株数 | 100株 |
| 株価 | 2,400円（→ 100株で24万円） |
| 優待 | QUOカード 1,000円 |
| 配当 | 1株20円 |
| 長期保有条件 | なし |

## STEP 0　銘柄の下調べ（前月〜）

会社のIRページで次を確認します。**優待情報サイトより会社の公式発表が優先**です。

- 権利確定日（何月末？20日？）
- 必要株数（100株？500株？）
- 長期保有条件の有無（「1年以上継続保有」などがあれば、1回のクロスでは優待が出ない）
- 優待の廃止・変更のお知らせが出ていないか

## STEP 1　日程を確認する

```
$ python -m yutai_cross dates 2026-12-31
権利確定日（基準日）: 2026-12-31(木)
  ※基準日が休場日のため、実質の基準日は 2026-12-30(水)
権利付最終日        : 2026-12-28(月)  ← この日の取引で買えば権利獲得
権利落ち日          : 2026-12-29(火)  ← この日に現渡し（この日以降。返済期日に注意）
SBI証券 一般信用(短期)（短期(15営業日)）の建て可能開始日（短期初日）: 2026-12-08(火)
楽天証券 一般信用(短期)（短期(14日)）の建て可能開始日（短期初日）: 2026-12-16(水)
```

→ **12月8日（火）〜12月28日（月）の間にクロス**し（楽天証券なら12月16日から）、**12月29日（火）に現渡し**します。

楽天証券の「14日」は土日祝を含む暦日なので、SBI証券の「15営業日」より建てられる期間が短くなります。

## STEP 2　コストを試算する

```
$ python -m yutai_cross cost --record 2026-12-31 --price 2400 --benefit 1000 --dividend 20
方法: SBI証券 一般信用(短期)
クロス日: 2026-12-28(月) → 現渡し: 2026-12-29(火)
コスト: 貸株料 153円（6日分） / 手数料 0円
利益: 847円
最低利益 300円 を確保できる最も早いクロス日: 2026-12-08(火)
```

- 最終日（12/28）にクロスすれば利益 **847円**
- 短期初日（12/8）に早めにクロスすると貸株料が666円に増えて利益 **334円**
- 年末は受渡しが 12/31〜1/3 をまたぐので、最終日クロスでも貸株料が6日分かかる点に注目

「在庫が残っていそうなら最終日、人気で在庫がすぐなくなりそうなら早め」が基本方針です（第7回）。

## STEP 3　在庫を確認する（発注の前夜〜当日朝）

一般信用売りは **在庫がないと注文できません**。

- SBI証券：銘柄の注文画面で「一般信用（短期）」の売建可能数量を確認。一般信用の売建可能銘柄一覧もある
- 楽天証券：「一般信用売建可能銘柄一覧」や注文画面で確認

在庫が「100株以上」あればOK。「0」や「×」なら、他の証券会社・他の信用区分（無期限など）を探します。

## STEP 4　発注する（前夜〜当日 8:59 まで）

**順番が大事：先に信用売り → すぐに現物買い**。在庫は売り注文を出した時点で押さえられることが多いので、売りが通らないのに現物だけ買ってしまう事故を防げます。

### ① 信用売り（新規売り）

| 項目 | 入力 |
|---|---|
| 取引 | 信用新規売（空売り） |
| 信用区分 | **一般信用（短期）** |
| 株数 | **100株** |
| 価格 | **成行** |
| 執行条件 | **寄付（寄成）** |

### ② 現物買い

| 項目 | 入力 |
|---|---|
| 取引 | 現物買 |
| 株数 | **100株**（①と同じ） |
| 価格 | **成行** |
| 執行条件 | **寄付（寄成）** |
| 預り区分 | **特定**（NISAにしない） |

両方とも「寄付で成行」なので、**9:00の寄付の同じ値段で約定**します。株数と執行条件をそろえるのがコツです。

> 証券会社によっては、クロスになる注文で「成行×成行（条件なし）」を受け付けないことがあります（仮装売買防止の注文制御）。**寄成（または引成）を指定**すれば発注できます。

## STEP 5　約定を確認する（9:00 以降）

- 「注文照会」で両方が **約定済み** か
- 「建玉一覧」に信用売り100株、「保有株式」に現物100株があるか
- **約定単価が同じ** か

### もし片方だけ約定していたら

| 状況 | 対処 |
|---|---|
| 売りだけ約定・買いが未約定 | 同じ日の **引成** で現物買い100株を入れる（大引けの値段で約定。数百円〜の値ズレは許容） |
| 買いだけ約定・売りが失効（在庫切れなど） | **同じ証券会社**の他の区分（無期限など）で売りを探す。なければ **現物を引成で売って撤退**（別の証券会社で売りを建てると、現物と信用売りが別々の口座になり、追証の計算で値上がり分が相殺されない） |
| ストップ高・ストップ安（特別気配） | 寄付で値がつかないと寄成の注文は約定せず失効することがある（扱いは証券会社ごとに確認）。大引けで比例配分になると、買いだけ・売りだけが（一部）約定することもある。約定株数を必ず確認し、差があれば残った側を解消する（権利付最終日の大引け後なら翌営業日に解消し、その回の優待はあきらめる） |

### 約定したら記録する

```
python -m yutai_cross position add X002 --method sbi_short --date 2026-12-08 --price 2400
```

記録しておくと、ツールがこの銘柄の「エントリー」の通知を止め、権利落ち日に返済期日つきで「現渡し」を知らせてくれます（第10回）。

## STEP 6　待つ

クロスが完成したら、権利落ち日まで **何もしない**。株価がどう動いても損益は相殺されています。

- ×「今日のうちに現渡ししておこう」→ **権利付最終日に現渡しすると権利がなくなります**
- ×「株価が上がったから現物だけ売ろう」→ クロスが崩れて損益リスクを抱えます

## STEP 7　現渡し（権利落ち日＝12/29）

| 証券会社 | メニューの例 |
|---|---|
| SBI証券 | 取引 → 信用取引 → 現引・現渡 → 対象の建玉を選んで「現渡」 |
| 楽天証券 | 国内株式 → 信用取引 → 現引・現渡 |

- 現渡しは当日の受付時間内に注文し、**その日の約定**として処理されます（受付時間は証券会社ごとに確認）
- **返済期日までに必ず**。短期初日に建てた場合は、権利落ち日がそのまま返済期日です。過ぎると強制決済になるので、権利落ち日に現渡しするのが基本です
- 「返済買い」ではなく **「現渡し」** を選ぶ

現渡しが終わると、現物も建玉も消えて、手元には「クロス前の現金 − コスト」が残ります。終わったら `python -m yutai_cross position close 建玉ID` で記録します。

## STEP 8　優待・配当を受け取る（2〜3ヶ月後）

- 優待は株主総会の前後（権利確定から2〜3ヶ月後）に郵送されてくるのが一般的
- 配当と配当落調整金も、配当額が確定した後に口座で精算されます
- 届いたら **`python -m yutai_cross position received 建玉ID --value 評価額` で記録**（`mydata/executed.csv` に1行追加されます）。確定申告のメモに使います（第8回）

## まとめ（1枚にすると）

```
[前月]   会社IRで優待内容・権利日・長期条件を確認
[数日前] dates / cost コマンドで日程とコストを確認
[前夜〜8:59] 在庫確認 → ①信用売り(寄成) → ②現物買い(寄成・特定)
[9:00〜] 約定確認（同株数・同単価）→ position add で建玉を記録
[権利落ち日] 現渡し（返済期日を過ぎない）
[2〜3ヶ月後] 優待到着 → 実績記録
```

## 宿題

1. `examples/watchlist_sample.csv` の銘柄で、`cost` コマンドを使って「最終日クロス」と「短期初日クロス」の利益を比べてみよう
2. 証券会社のデモ画面や注文画面を開いて、「信用新規売」「一般信用（短期）」「寄付」を選ぶ場所を確認しておこう（まだ発注はしない）
