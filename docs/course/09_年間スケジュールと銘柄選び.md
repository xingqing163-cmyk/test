## 2. 月ごとの特徴

- **3月・9月**：決算・中間決算が集中し、優待銘柄が最も多い。そのぶん在庫争奪も最も激しい
- **6月・12月**：3月・9月に次いで多め。12月は **年末年始で受渡日の間隔が空く** ので、貸株料・逆日歩の日数が増える
- **その他の月**：銘柄数は少ないが、ライバルも少なく在庫が残りやすい「穴場」
- **月末以外（20日・15日など）**：見落とされやすく、在庫が残っていることも

最初は **3月・9月以外の月で練習** し、慣れた状態で3月・9月の本番を迎えるのがおすすめです。

## 3. 銘柄選びの基準（チェックリスト）

1. **一般信用で売れるか**（証券会社の売建可能銘柄一覧で確認）
2. **長期保有条件がないか**
3. **利回り**：利益 ÷ 必要資金。資金が少ないうちは株価の安い銘柄が有利
4. **自分が使える／換金できるか**：使わない優待は換金価値で評価
5. **利益の最低ライン**：初期設定は300円。手間を考えて自分で決める
6. **勤務先・取引先ではないか**

## 4. 情報源

| 情報 | どこで見る |
|---|---|
| 優待内容・権利日・長期条件（一次情報） | 各社のIRページ・適時開示 |
| 優待銘柄の検索 | 証券会社の株主優待検索、優待情報サイト、優待本など |
| 一般信用の在庫 | 各証券会社の画面（ログインが必要） |
| 逆日歩・貸借残高 | 日本証券金融（taisyaku.jp）、JPXの信用取引残高等 |

※ツールは優待情報や在庫を自動では取りに行きません（多くのサイトはログインや利用規約の制約があるため）。ウォッチリストに自分で入力する形です。

## 6. 年間の目安（イメージ）

利益は資金・手間・在庫の取れ方で大きく変わります。例えば「1回あたり利益1,000円 × 月4銘柄 × 12ヶ月」なら年約5万円。資金を増やし、3月・9月にしっかり在庫を取れるようになると、もう一段上を狙えます。**最初の半年は「事故ゼロ」を最優先** にしてください。

## 宿題

1. 翌月と翌々月に権利がある優待銘柄を5つ探し、ウォッチリストに入れよう
2. 自分の「利益の最低ライン」を決めて、設定 `min_profit_yen` に入れよう
