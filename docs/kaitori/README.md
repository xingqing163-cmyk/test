# 買取差益チェック（ヤフショで仕入れ → 買取サイトに売る）

買取サイトの「新品の買取価格」と、Yahoo!ショッピング（ヤフショ）の販売価格・ポイントを商品ごとに比べ、
**仕入れて買取に出すと黒字になる商品**を一覧にするツールです（`kaitori_check/`、Python 3.9+、追加ライブラリ不要）。
カメラ本体・レンズを想定していますが、型番やJANコードのある新品の商品なら同じように使えます。

> **免責事項**：ツールの出力は取得時点の価格にもとづく試算で、正確性を保証しません。買取価格・販売価格・在庫・ポイントはすぐに変わり、買取は到着時の検品で減額されることがあります。税金の説明は2026年10月時点で作成者が調べた一般的な内容で、個別の判断は税務署・税理士に確認してください。記載のサイト・会社とは関係がありません。

## しくみ

```
買取サイトの一覧ページ ──fetch──▶ mydata/kaitori_list.csv（商品名・JAN・新品買取価格）
                                         │
                                       check（1商品ずつヤフショAPIで検索：JAN → なければ商品名）
                                         ▼
          mydata/reports/kaitori_日時.html / .csv（利益の大きい順。黒字・薄利・赤字・見つからず）
```

- **JANコードで見つかった商品**は同じ商品とみなします（「一致=JAN」）
- **商品名で見つけた商品**は推定です（「一致=名前(要確認)」）。型番がすべて一致し、世代違い（Mark II / III、GM II など）・キット違いでないものだけを候補にしますが、色・付属品・国内正規品かどうかは必ずページで確認してください
- 新品・在庫ありの商品だけを安い順に検索し、中古・訳あり・展示品・並行輸入などの言葉がある商品は除きます

## はじめての人の手順

コマンドの `python` は、Windows なら `py`、Mac なら `python3` に読み替えてください（[リポジトリのREADME](../../README.md) の「はじめての人の最短手順」1〜3 と同じ準備です）。

1. **ヤフショAPIの Client ID を発行する**（無料）
   1. Yahoo! JAPAN ID でログインした状態で、Yahoo!デベロッパーネットワークの「アプリケーションの管理」→「新しいアプリケーションを開発」を開く
   2. 画面の案内に従って登録する（ID連携は使わないので、選択肢があれば使わない方を選ぶ）
   3. 発行された **Client ID** がアプリケーションIDです。他人に見せないでください（画面の項目名は変わることがあります）
2. `python -m kaitori_check init` で `mydata/kaitori_settings.json` を作る
3. `mydata/kaitori_settings.json` をメモ帳などで開き、`"yahoo_appid": ""` の `""` の中に Client ID を書く。
   ほかの項目（ポイント・送料・消費税）も自分の条件に合わせる（下の「設定」）
4. `python -m kaitori_check fetch` で買取サイトの価格一覧を `mydata/kaitori_list.csv` に保存する。
   **Excel で開いて、商品名と買取価格が正しく読めているか確認**（区分が「新品」以外の価格を拾っていないか）
5. `python -m kaitori_check check` で判定する。画面に黒字・薄利の商品が出て、`mydata/reports/` に HTML（リンク付き）と CSV ができる
6. 気になる商品は、HTML のリンクから **買取サイトとヤフショの両方のページを開いて** 下の「仕入れ前のチェックリスト」を確認してから買う

```bash
python -m kaitori_check check --limit 50            # 買取価格の高い50商品だけ調べる（APIは1商品1〜2回）
python -m kaitori_check check -k EOS                # 商品名に EOS を含むものだけ
python -m kaitori_check check --min-price 50000     # 買取価格5万円以上だけ
python -m kaitori_check check --show-loss           # 赤字の商品も画面に出す
python -m kaitori_check calc --sell 105000 --buy 98000 --points 4450   # 1商品を手入力で計算
```

商品数が多いと、ヤフショAPIの間隔（既定1秒）×商品数だけ時間がかかります（300商品で5〜10分）。

## 利益の計算

```
現金利益 = 買取価格 − 仕入価格（税込） − 仕入れの送料 − 買取サイトへの送料 − 振込手数料 − その他経費 − 消費税の増加分
利益     = 現金利益 + ポイント × 1ポイントの円換算
利益率   = 利益 ÷（仕入価格 + 仕入れの送料）
```

- **ポイント**：APIが返す付与ポイント（通常・ボーナスの大きい方）に、設定の `extra_point_rate`（税抜価格×率）を足します。APIのポイントにはストアのボーナスが入りますが、PayPayカード払い・5のつく日などの上乗せは入らないので、**確実にもらえる分だけ** `extra_point_rate` に書いてください。ポイントは付与まで時間がかかり、期間限定ポイントは使い道が限られます。資金繰りが厳しいときは `judge_with_points` を `false` にして現金だけで判定するのが安全です
- **送料**：ヤフショ側が「送料無料」表示でない（不明を含む）商品は `assumed_shipping_yen` を足します
- **消費税**：下の「消費税」の設定で、取引によって増える納付額の目安を引きます
- **所得税・住民税は引いていません**（税引前の利益です）
- 判定：利益が `min_profit_yen` 以上かつ利益率が `min_profit_rate` 以上なら **◎黒字**、0円より多ければ **△薄利**、それ以外は **×赤字**

## 設定（mydata/kaitori_settings.json）

| 項目 | 既定 | 意味 |
|---|---|---|
| `yahoo_appid` | 空 | ヤフショAPIの Client ID。空なら環境変数 `YAHOO_APPID` |
| `lyp_premium` | false | LYPプレミアム会員なら true（会員価格・会員向けポイントがあればそちらで計算） |
| `extra_point_rate` | 0 | APIに出ない自分の上乗せポイント率（例: 2% なら 0.02） |
| `point_value` | 1.0 | 1ポイントを何円とみなすか |
| `judge_with_points` | true | false で現金だけで判定 |
| `assumed_shipping_yen` | 1000 | ヤフショ側が送料無料でないときの見込み送料 |
| `send_shipping_yen` / `transfer_fee_yen` / `other_cost_yen` | 0 | 買取サイトへの送料・振込手数料・梱包材などの1点あたりの額 |
| `tax_mode` | exempt | 消費税の扱い（下の表） |
| `min_profit_yen` / `min_profit_rate` | 1000 / 0.02 | 黒字と判定する最低利益と利益率 |
| `price_floor_ratio` | 0.6 | 名前で探したとき、買取価格の6割未満の商品は別商品・付属品として除外 |
| `exclude_words` / `caution_words` | （例を参照） | 除外する言葉／注意を出す言葉 |
| `sites` | SY買取 カメラ | 価格を取得する買取サイトの一覧ページ（下の「買取サイトを追加する」） |

### 消費税（tax_mode）

| あなたの状況 | tax_mode | 計算 |
|---|---|---|
| 免税事業者（インボイス未登録で、2年前の課税売上高が1,000万円以下など） | `exempt` | 0 |
| インボイス登録をきっかけに課税事業者になり、**2割特例**を使う | `special`（`special_ratio`: 0.2） | 買取価格×10/110×0.2 |
| 簡易課税を届け出ている | `simplified`（`deemed_purchase_rate`: 0.9） | 買取価格×10/110×(1−0.9) |
| 本則課税 | `general` | (買取価格 − 仕入・送料などの経費)×10/110 |

- 買取業者（事業者）への販売は、簡易課税では**第1種事業（卸売業）・みなし仕入率90%**に当たると考えられます
- **2割特例は2026年分（令和8年分）まで**です。2027年分以降の経過措置は、その時点の国税庁の案内を確認して `special_ratio` を合わせてください
- 本則課税で仕入税額控除を受けるには、ストアのインボイス（適格請求書）が必要です。インボイス登録のないストアからの仕入れは、2026年10月1日〜2029年9月30日は仕入の消費税の50%だけ控除できる経過措置があります。そうした仕入れが多ければ `input_credit_ratio` を下げてください

## 買取サイトが読み取れないとき

`fetch` は、ページに埋め込まれた商品データ → HTMLの商品カードの順に試し、いちばん多く取れた方を使います。
「商品を読み取れませんでした」と出たり、商品名・価格がずれていたりするときは：

1. **ブラウザで保存して読み込む**：ブラウザで一覧ページを表示し（全ページ分）、「名前を付けて保存」→「ウェブページ、完全」で保存して
   `python -m kaitori_check fetch --html 保存したファイル.html --site SY買取 --url 一覧ページのURL --category カメラ`
2. **CSVを手で作る**：Excel で `商品名,JAN,買取価格` の3列（JANは空でも可。あれば検索が正確）を作り、
   `python -m kaitori_check check -i そのファイル.csv`
3. `fetch --save-raw` で取得したHTMLが `mydata/kaitori_raw/` に保存されます。読み取り方をサイトに合わせて直すときの材料になります

robots.txt で自動取得が禁止されているサイトは取得しません（1. か 2. を使ってください）。自動取得はサイトの利用規約も確認し、個人の確認用途で、間隔をあけて（既定2秒）行ってください。

## 買取サイトを追加する

`mydata/kaitori_settings.json` の `sites` に1行ずつ足します。カメラ本体とレンズでページ（カテゴリ）が分かれていれば、それぞれ1行にします。

```json
"sites": [
  {"name": "SY買取", "category": "カメラ本体", "url": "https://www.sy-kaitori.com/products?category=..."},
  {"name": "SY買取", "category": "レンズ", "url": "https://www.sy-kaitori.com/products?category=..."},
  {"name": "別の買取サイト", "category": "カメラ", "url": "https://...", "enabled": false}
]
```

`python -m kaitori_check fetch --site SY買取` で1サイトだけ取得できます。

## 仕入れ前のチェックリスト

- [ ] **買取条件**：新品未開封のみか、シュリンク・外箱・保証書（購入日・店舗印の有無）・購入からの日数に条件がないか
- [ ] **買取価格の確定時期**：申込時か到着時か。価格保証の期限内に届けられるか（ヤフショの発送日数も見る）
- [ ] **減額条件**：箱の傷・凹み、付属品の欠品、メーカー保証の登録状況など
- [ ] **同一商品か**：型番・色・キット構成・国内正規品（並行輸入品でない）・JAN
- [ ] **ストア**：評価の件数と内容、転売目的の購入を断る旨の記載や購入数の制限がないか、極端に安い場合は詐欺ストアでないか
- [ ] **ポイント**：付与時期（すぐには使えない）・期間限定かどうか・上限
- [ ] **資金**：入金までの日数（仕入れのカード引き落としと買取代金の入金のタイミング）
- [ ] 届いたら**開封せず**に検品（外箱の状態を写真に残す）し、早めに発送する

## 会計・税金メモ（副業で確定申告している人向け）

一般的な処理の例です。迷ったら税務署・税理士に確認してください。

**帳簿のつけ方の例**

| 取引 | 借方 | 貸方 |
|---|---|---|
| ヤフショで仕入れ（カード払い） | 仕入高 | 未払金 |
| 仕入れの送料 | 仕入高（仕入原価に含める） | 未払金 |
| 買取サイトへ発送 | 荷造運賃 | 現金など |
| 買取価格が確定（査定額を承諾） | 売掛金 | 売上高 |
| 買取代金が入金 | 普通預金・支払手数料（振込手数料） | 売掛金 |
| 仕入れで貯まったポイントを使った | （使った支払いの科目） | 雑収入 |

- **売上の日付**：原則は商品を引き渡した日です。買取では査定額を承諾して売買が成立した日を売上日にするのが自然です。どの日にするか決めたら毎年同じ基準で
- **ポイント**：事業の仕入れで貯まったポイントは、使ったときに「雑収入」に計上するのが一般的です（使った仕入れを値引き後の金額で計上する方法もあります）。どちらかに統一します。もらった時点では計上しない扱いが一般的です
- **年末の在庫**：12月31日時点で手元にある（または発送済みで査定前の）商品は、仕入価格で「期末商品棚卸高」に計上し、その年の経費（売上原価）から除きます
- **所得の区分**：開業届を出して継続的に行っているなら事業所得、そうでなければ雑所得になるのが一般的です。事業所得で青色申告（e-Taxで提出・複式簿記）なら最大65万円の控除があります
- **会社員との両立**：確定申告書の住民税の欄で「自分で納付（普通徴収）」を選ぶと、副業分の住民税は勤務先経由ではなく自分で納める形になります（勤務先の副業規程は必ず確認してください）
- **古物商許可**：新品をヤフショのストア（小売店）から買って買取業者に売るだけなら一般に不要とされますが、フリマアプリやオークションで個人から仕入れて売る場合は必要になります。取引の形が変わるときは最寄りの警察署に確認してください
